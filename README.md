# 🌦️ Weather App

A simple and intuitive Weather App that provides real-time weather updates for any location. Built using React, this app fetches weather data from an API and displays key metrics like temperature, humidity, wind speed, and more.

## 🚀 Features

- 🌍 **Search by City** – Get weather updates by entering a city name.
- ⏳ **Real-time Data** – Fetches up-to-date weather conditions.
- 🌡️ **Temperature & Weather Details** – Displays temperature, humidity, wind speed, and more.
- 🎨 **Clean UI** – User-friendly and responsive design.

## 🛠️ Tech Stack

- **React** – Frontend library
- **CSS/Styled Components/Material UI** – For styling
- **Weather API** – Fetches real-time weather data
- **Axios** – For API calls

## 📦 Installation & Setup

1. Clone the repository:
   ```sh
   git clone https://github.com/mumpysd/weather-app.git
   cd weather-app
   ```
2. Install dependencies:
   ```sh
   npm install
   ```
3. Get an API key from [OpenWeather](https://openweathermap.org/api) (or any other weather API).
4. Create a `.env` file in the root and add:
   ```sh
   REACT_APP_WEATHER_API_KEY=your_api_key_here
   ```
5. Start the development server:
   ```sh
   npm start
   ```
